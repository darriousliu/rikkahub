# HugeIcons source notice

The Kotlin `ImageVector` sources in this module were selected from the 1.3 tag
of [rikkahub/hugeicons-compose](https://github.com/rikkahub/hugeicons-compose),
commit `80cc7a83c686d9729f410a71b75fc52de0773f55`.

Only the 144 stroke icons imported by RikkaHub, together with the root
`HugeIcons` object, are vendored. The icon designs originate from the
Hugeicons free stroke-rounded collection. The official
`@hugeicons/core-free-icons` package declares the MIT license.
